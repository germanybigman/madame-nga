# Buyer Handoff Package

This folder contains the handoff materials prepared for the buyer or restaurant owner:

- BUYER_HANDOFF.md — concise summary suitable for the buyer
- BUYER_EMAIL_TEMPLATE.md — template email to send to the restaurant owner
- ADMIN_USER_SETUP.md — instructions for creating the admin account in Supabase
- MAINTENANCE_AGREEMENT_TEMPLATE.md — sample support/maintenance agreement
